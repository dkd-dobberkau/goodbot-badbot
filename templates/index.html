Discovery Reads — who fetches llms.txt, agents.md, grounding pages & the API catalog

These files are invitations, not traps: /llms.txt is the LLM-oriented site summary, and /agents.md (served at /AGENTS.md, /agents.md and /.well-known/agents.md) is a probe surface for agents that look for usage instructions. The /.well-known/api-catalog goes one step further: it offers a machine-readable description of the JSON stats API, so an agent can use the interface instead of scraping this page. Reading any of them is not a violation — it is the opposite signal: an agent deliberately doing discovery. So far — discovery reads have been logged.
